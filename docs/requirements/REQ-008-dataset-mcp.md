## Outcome

An application domain’s data set—typically corresponding to one existing database—is exposed as an MCP for that domain, as described in `docs/product.md`.

## Scope

### In

- One MCP per application domain / data set (typically one database).

### Out

- User-facing inquiry UX (see REQ-002–REQ-005).
- Cross-database federation logic (see REQ-006).
- Semantic mapping content (see REQ-007).
- Orchestration that calls multiple MCPs (see REQ-009).
